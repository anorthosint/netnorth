NetNorth - 

● Инструмент для визуализации связей (графов) и построения интеллект-карт. 
Сделан для OSINT-исследований, структурного анализа данных и быстрой сборки схем.

Функционал:
1. Работа с узлами: создание текстовых узлов и взаимодействие с ними
2. Связи: построение направленных графов с опцией авторасстановкой.(опцию можно откючить в настройках)
3. Форматирование: изменение цвета текста, подчеркивание, выделение маркером.
4. Сохранение проектов: проекты сохраняются в главном меню.
5. Экспорт и импорт: сохранение проекта в JSON, также форматы PNG/JPG. 
6. Анимация построения графов: эта функция нужна, чтобы посмотреть всю проделанную работу в ускоренном режиме.
