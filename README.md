NetNorth - 

● Инструмент для визуализации связей (графов) и построения интеллект-карт. 
Сделан для OSINT-исследований, структурного анализа данных и быстрой сборки схем.

Функционал:
1. Работа с узлами: создание текстовых узлов и взаимодействие с ними
2. Связи: построение направленных графов с опцией авторасстановкой.(опцию можно откючить в настройках)
3. Форматирование: изменение цвета текста, подчеркивание, выделение маркером.
4. Сохранение проектов: проекты сохраняются в главном меню.
5. Экспорт и импорт: сохранение проекта в JSON, также форматы PNG/JPG. 
6. Анимация построения графов: эта функция нужна, чтобы посмотреть всю проделанную работу в ускоренном режиме. 


NetNorth

● A tool for visualizing connections (graphs) and building mind maps. Designed for OSINT research, structural data analysis, and rapid diagram assembly.
Features:
Working with nodes: Creating text nodes and interacting with them
Connections: Building directed graphs with an auto-arrange option (can be disabled in the settings).
Formatting: Changing text color, underlining, and highlighting.
Project saving: Projects are saved in the main menu.
Export and import: Saving projects to JSON, as well as PNG/JPG formats.
Graph building animation: This feature allows you to review all the work done in an accelerated playback mode.
